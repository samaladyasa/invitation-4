# Western Save The Date

A React + Vite wedding invitation website with custom animated sections, photo galleries, and celebration details.

## Features

- Built with React and Vite
- Smooth scroll and reveal animations using GSAP
- Custom sections for hero, event details, countdown, gallery, story, and footer
- Responsive layout with handcrafted visuals

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Start the development server:
   `npm run dev`
3. Open the app in your browser at:
   `http://localhost:3000`

## Build

- Build for production: `npm run build`
- Preview the production build: `npm run preview`
